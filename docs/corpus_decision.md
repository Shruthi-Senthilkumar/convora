# Corpus Decision — Phase 0

## Decision
Primary evaluation corpus: self-recorded sessions + AMI Meeting Corpus.
Switchboard/Fisher: NOT USED.

## Rationale
Switchboard-1 Release 2 (LDC97S62) fees confirmed via LDC catalog
(https://catalog.ldc.upenn.edu/LDC97S62):
  - Members: $0.00
  - Non-Member: $3,000.00
  - Reduced-License: $1,500.00

No institutional LDC membership available. Cost is not justified for a
self-funded solo portfolio project. Fisher follows the same LDC licensing
model and is excluded on the same grounds without needing separate pricing
confirmation.

AMI Meeting Corpus is freely available under CC BY 4.0
(https://groups.inf.ed.ac.uk/ami/corpus/), no membership or fee required.
